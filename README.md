# Research Project: Is GDP a True Measure of a Nation's Growth and Success?

## Overview
This repository contains the complete empirical research dossier, secondary dataset audit, reproducible processing scripts, and preliminary statistical computations for the research proposal:
> **"Is GDP a True Measure of a Nation's Growth and Success? A Comparative Longitudinal Panel Study (2000–2023)"**

## Directory Structure
```
.
├── Research proposal writing .pdf       # Course proposal writing guidelines
├── Research_Proposal-3.pdf              # Working research proposal draft
├── Research_Proposal_Group_102.pdf      # Initial group proposal draft
├── README.md                            # Repository overview
└── research_output/                     # Complete research dossier & assets
    ├── dossier.md                       # Comprehensive Research Dossier
    ├── panel_coverage_matrix_summary.csv # Longitudinal panel coverage matrix
    ├── undp_indicator_coverage_2000_2023.csv # Annual UNDP country coverage counts
    ├── world_bank_indicator_coverage_2000_2024.csv # Annual World Bank country coverage counts
    ├── country_coverage_breakdown_2000_2023.csv # Country-by-country data availability
    ├── country_coverage_breakdown_2010_2023.csv # 2010-2023 IHDI sub-panel availability
    ├── matched_country_data_2023.csv    # Cross-sectional matched dataset for 2023
    ├── preliminary_correlations_2023.csv # Pearson & Spearman correlation results
    ├── preliminary_rank_diff_summary_2023.csv # Rank difference distribution (GDP vs IHDI/PHDI)
    ├── preliminary_matched_country_pairs_2023.csv # Matched country pairs (+/-10% GDP pc)
    ├── verified_literature_metadata.json # Verified CrossRef API metadata for 31 sources
    ├── raw_data/                        # Raw downloaded files (UNDP HDR 2025, WB WDI)
    └── scripts/                         # Fully reproducible Python extraction scripts
```
